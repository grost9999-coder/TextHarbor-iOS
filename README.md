# 字捕手｜TextHarbor

iPhone 原生 SwiftUI 文字擷取 App（iOS 17+）。App 在 iPhone 主畫面顯示名稱為「字捕手」，GitHub 專案與技術代號保留 TextHarbor，既有 Bundle ID `com.grost9999.textharbor` 不變。

## 功能
- 影片畫面 OCR
- 影片下方字幕 OCR
- 影片音軌轉文字（Apple Speech）
- 照片及截圖批次辨識
- 網頁內文擷取
- 按畫面順序合併、去除重複文字
- 編輯、複製、本機文件庫、全文搜尋、TXT 與 PDF 匯出

## 建置與安裝
使用 Xcode 開啟 `TextHarbor.xcodeproj`，選取 `TextHarbor` Scheme。
GitHub Actions 在 macOS runner 執行不需要簽署的 iOS Simulator 編譯檢查。
要安裝到 iPhone 或上傳 TestFlight，另外需要設定 Apple Developer 帳號與簽署，並建立發布工作流程。

## 限制
文字辨識仍須人工校對，影片抽樣可能遺漏閃現字幕。部分網頁禁止存取。
此專案目前仍在驗證編譯階段，不代表已通過實機或 TestFlight 測試。

## 隱私
照片與影片畫面 OCR 使用 Apple Vision 裝置端處理；語音辨識服務可能需要網路。擷取文件儲存在 App 本機沙盒，刪除 App 可能失去文件，請定期匯出備份。

## 影片文字辨識改進（2026-11-14）

針對約 2 分 42 秒、886×1920 的直式畫框錄影，以及內容中途轉成側向顯示的畫面：

- **捲動清單／商品代碼模式（預設開啟）**：依第一次出現順序保留不同文字行，使用精確比對去除重複，避免誤刪相似商品代碼。相同文字只保留一次，不適合需要保留多次相同句子的影片。
- **一般影片模式**：僅移除短時間內重複的文字行，隔一段時間再次出現的文字可以保留。
- **高精度完整擷取（預設開啟）**：約每 0.25 秒取樣，最多約 1,600 格；嘗試放大較小文字，並在辨識變弱時重新檢查旋轉方向。若處理時間過長可關閉。
- **查核工具**：可展開完整結果、切換「未去重原文」、查看抽樣數、成功數、重複行、失敗影格及旋轉偵測統計。
- **長片保護**：可停止處理並保留停止前的文字。
- GitHub Actions 會執行 `Tests/TextMergeChecks/main.swift` 的文字保留測試及 iOS 模擬器編譯。

### 重測步驟

1. 用 Codemagic 的 `ios-testflight` 工作流程，從最新 `main` 分支建置並成功上傳 Apple。
2. 在 App Store Connect 將新的 Build 加入內部測試群組，於 TestFlight 更新。
3. 用同一支錄影，選擇「影片畫面」與「捲動清單／商品代碼模式」，開啟「高精度完整擷取」。
4. 比較：合併後字數、未去重原文、OCR 原始行數、合併後行數與失敗影格數。若仍漏字，保留兩份輸出進行逐段人工比對。

此更新**尚未針對該錄影完成 iPhone 實機端到端準確率驗證**，不能宣稱保證擷取全部文字。影片壓縮、轉場及高速滑動都可能導致文字無法識別。請勿將含私人資料的錄影上傳至公開 GitHub 儲存庫。
